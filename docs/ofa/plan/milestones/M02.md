## Order (write each test file first, see it fail, then implement)
1. `lexicon.py` + `test_lexicon.py`: table of ≥ 60 cases (EN/HI Devanagari/Roman Hinglish), incl. "yes but change it" → MODIFY, "okay" → UNCLEAR, "haan mat bhejo" → NO, "नहीं" → NO, "ji haan bhej do" → YES.
2. `tiers.py` + `test_tiers.py`: verb table; unknown → 2; engine hint can raise only; effect lexicon on element labels ("Send", "Post", "Pay now", "भेजें", "Submit application"); Enter in compose; shell allowlist.
3. `approval.py`: `ApprovalStore` (in-memory, per epoch), `ask(step) -> ApprovalRequest`, `on_transcript(t)`, `invalidate_all(epoch)`; deterministic `render_spoken(step)` templates (EN + HI). Digest = sha256(canonical json). Listener interface:
   ```python
   class ApprovalListener(Protocol):
       async def listen(self, req: ApprovalRequest, window_s: float = 8.0) -> FinalTranscript | None
   ```
   Fake listener for tests; real listener wired to session/echo guard (M01) behind the same protocol.
4. Gate integration (`ofa_execution/policy.py`): `Gate.check` calls `tiers.classify`; Tier 2 requires a GRANTED request whose digest equals the recomputed step digest; `Gate.consume` marks CONSUMED; epoch mismatch refuses. Keep existing `sign/consume` semantics; add digest fields. Existing tests in `tests/local_execution` must stay green.
5. `audit.py` + test: JSONL hash chain, redaction, `show`/`purge` CLI.
6. `egress.py` + `canary.py` + tests: `guard(payload: str|bytes|dict) -> same` raises `LeakBlocked`; fingerprints raw/lower/b64/urlenc/hex/no-whitespace; logging handler filter installed at startup; synthetic canaries per session.
7. Vault: `store.py` (SQLite, AES-GCM, AAD=handle, DPAPI-wrapped key via `voice/protected_store.py`), `unlock.py` (Hello via winrt `UserConsentVerifier`, fallback CredUI; fake in tests), `handles.py` (parse/format/validate, meta), CRUD + rotate/revoke/delete/export(encrypted).
8. `broker.py`: `fill(handle, field_ref, step)` flow from 05 with `TargetIdentity` providers (fake browser/app in tests): exact origin, https, no cert error, same-origin frame, no redirect since observe, IDNA/confusable check (`unicodedata` NFKC + skeleton map), app exe + publisher. Returns `{ok, reason}` only.
9. `test_no_bypass.py`: AST scan — only `ofa/engine/*` may import httpx for `api.groq.com`; only `audit.py`/logging setup write log files; harness/hands modules cannot import `ofa.vault.store`.
