# M05 — Desktop Harness + C2/C3
**Purpose:** generic control of any Windows app/site · **Depends on:** M03 · **Files likely touched:** `api/ofa/harness/{api,uia,ocr,vision,redact,discovery,fake}.py`, `api/ofa/harness/adapters/*.yaml`, `api/ofa_execution/{windows,engine}.py`, `api/tests/ofa/test_{harness,c2,c3,discovery}.py` · **Done when:** H1–H8, R6, V4 pass.

Read: §5 C2–C3, §9, §10.1; plan 07, caps/C2, caps/C3, 04 §Tier classifier.

## Steps
1. `grep -n "def \|class " ofa_execution/windows.py` → reuse UIA walk, SendInput, window verification; do not duplicate.
2. `harness/api.py` helper set per 07 with `Element` dataclass; a `HarnessHand(Hand)` registers in `ofa_execution.Engine` so every helper call is a `Step` through Gate.
3. `uia.py` bounded tree → Elements (`source="uia"`, `is_password` from `IsPassword`).
4. `ocr.py`: winrt `OcrEngine.TryCreateFromUserProfileLanguages()`; capture window via `PrintWindow`/BitBlt → SoftwareBitmap → lines/words with bbox (`source="ocr"`). Report installed OCR languages in `doctor`.
5. `redact.py`: `redact(RawImage, elements, filled_fields, user_regions) -> RedactedImage` (V4). `vision.py`: only if `engine.info().supports_vision` and `OFA_VISION=on`, else `BLOCKED_NO_VISION` (R6).
6. `discovery.py`: AppsFolder (`shell:AppsFolder` via PowerShell `Get-StartApps` once, cached) + App Paths + running windows; fuzzy resolve with `AMBIGUOUS` options.
7. C2 verbs + failure modes (caps/C2) as tools; each returns verified state.
8. C3 generic loop; effect-label tiering (04) on `click`/`key`.
9. Adapters: YAML schema `{app, version, match: {exe|title|origin}, hints: {search_box, compose_field, send_button}}`; WhatsApp, Slack, VS Code, Cursor, Chrome/Edge (hints only).
10. Windows tests on `ofa_execution/testpad.py` (open, type, click, scroll, read back). User-run script `scripts/demo_noadapter.ps1`: voice-open Settings → Bluetooth page; Notepad type+save-as to temp (Tier 2 overwrite check).
