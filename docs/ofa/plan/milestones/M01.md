## Interfaces
```python
class SessionState(Enum): OFF, IDLE, LISTENING, THINKING, ACTING, SPEAKING, AWAITING_APPROVAL, ERROR
class Session:
    epoch: int; state: SessionState
    def toggle(self) -> None            # Caps handler; start or stop(kill)
    def set_state(self, s) -> None      # notifies overlay + subscribers
    def subscribe(self, cb) -> None
    on_stop: list[Callable[[int], None]]  # approval store, executor, tts register here
class EchoGuard:
    def note_tts(self, text: str, t_end: float) -> None
    def is_echo(self, transcript: str, t_start: float) -> bool   # partial_ratio>=80 vs last 30 s, or t_start < t_end+0.4 for approvals
```
`TurnHandler` protocol: `async def handle(text, lang, epoch) -> None` — M01 uses an **echo bot** (speaks back a short ack) until M03 plugs the orchestrator.

## Steps
1. Read `voice/session.py`, `voice/runtime.py`, `voice/hotkey.py`, `voice/overlay.py` by `grep -n "def \|class "` then targeted ranges. Do not rewrite working parts.
2. `ofa/session.py` + tests (fake clock, fake hotkey): toggle, epoch, multi-turn, silence never stops.
3. Hotkey: confirm hook swallows Caps (no toggle); Shift+Caps passes. Windows test reads `GetKeyState(0x14)` before/after a synthetic press (`SendInput`) — mark `windows`.
4. Overlay: map 7 states to colors/animation; topmost, click-through, top-center; mic-live ring tied to `audio.streaming`. Test: state→render params (no pixels).
5. `ofa/voice_router.py`: table from 03 as data (`ROUTES = {(capability, lang): [provider,...]}`), initial picks: STT Deepgram nova-3 multi (existing) + add **Flux** `/v2/listen` `flux-general-multi` client in `voice/deepgram.py` (end-of-turn events → `Transcript.end_of_turn`); Gradium STT for en; TTS Deepgram + Gradium. Announce voice fallback once.
6. Echo guard + barge-in: speaker mode gating (existing) + `EchoGuard`; headphone mode: STT partial during SPEAKING → stop TTS ≤ 200 ms. Try WASAPI communications capture (sounddevice `WasapiSettings`?) — if not exposed, log PLAN-DELTA "no AEC; gating only".
7. Voice controls matcher (stop/cancel/pause/resume/ruko) before turn handler.
8. `python -m ofa` runtime: Caps → session → mic → router STT → echo bot → TTS. `--fake` uses `voice/fakes.py`.
9. Live smoke (budget 10/10): say 3 EN + 2 HI phrases per provider; record latency in `docs/ofa/bench/m01-smoke.md`.
