## Steps
1. **Checkpoint api** (recoverable, no secrets):
   ```powershell
   cd one-for-all-api
   git status --porcelain
   git stash push -u -m "pre-ofa checkpoint 2026-11-26"   # E-Brain evidence edits
   git stash list | Select-Object -First 1
   ```
   web: `git -C ../one-for-all-web stash push -m "pre-ofa checkpoint"` only if web files will be edited (not before M11).
2. **Pick the base ref** by evidence, not docs:
   ```powershell
   git fetch --all --quiet
   foreach($r in 'origin/staging','origin/main','feat/voice-pipeline','main'){ git log -1 --format="$r %h %ci" $r; git ls-tree --name-only $r voice ofa_execution }
   ```
   Base = newest ref that contains both `voice/` and `ofa_execution/`. If none has both: newest with `voice/`, then `git merge --no-ff` the ref holding `ofa_execution/` (feat/local-execution-foundation); conflicts → stop, NEEDS-OPUS.
   `git switch -c feat/ofa-core <base>`.
3. **Deps:** create `requirements-ofa.txt` = union of `requirements-voice.txt` + `requirements-local-execution.txt` + `rapidfuzz`, `indic-transliteration`, `winrt-runtime`, `winrt-Windows.Media.Ocr`, `winrt-Windows.Security.Credentials.UI`, `winrt-Windows.Graphics.Imaging`, `winrt-Windows.Storage.Streams`, `pytest`, `pytest-asyncio`. Pin exact latest versions that install on Py 3.12 (`uv pip compile` → `requirements-ofa.lock`).
   ```powershell
   uv venv --python 3.12 .venv-ofa
   uv pip install --python .venv-ofa/Scripts/python.exe -r requirements-ofa.txt
   ```
   Add `.venv-ofa/` to `.gitignore`.
4. **`ofa/config.py`**: pydantic-settings-free loader: reads process env + optional `--env-file` (python-dotenv, `override=False`). `groq_key()` → `GROQ_API_KEY`, else `GROQ_API_KRY` + single `logging.warning("GROQ_API_KRY is misspelled; rename to GROQ_API_KEY")`. Keys typed `SecretStr`. `OFA_ENGINE` default `groq`. Never `repr` values.
5. **`ofa/live_budget.py`**: `spend(provider, n=1)` reads/writes `../docs/ofa/bench/live-calls.json` (workspace root docs; path via `OFA_BENCH_DIR`), raises `BudgetExceeded` over 00-INDEX caps (dict constant).
6. **`python -m ofa doctor`**: prints OS version, Python, mic device count, UIA available, Windows OCR languages, which key *names* are set (never values), Hello availability.
7. **Key probes** (live, 1 each, through `live_budget`): Groq `GET /openai/v1/models` (200), Deepgram `GET https://api.deepgram.com/v1/projects` (200), Gradium: one 1-word TTS request via existing `voice/gradium.py` (non-empty audio). Print status code only. Missing key → log need N2 in PROGRESS and continue.
8. **Run existing apps** once: `python -m voice --help`; `.venv-ofa/Scripts/python.exe -m ofa_execution --test-pad` (close after page opens); existing tests: `python -m pytest tests/voice tests/local_execution -q -x 2>&1 | Select-Object -Last 15`. Record pass/fail counts.
9. Re-verify 01 claims (Caps hook works, orb shows) by running `python -m voice --fake` if available; log deltas.
