# M03 — ReasoningEngine + Groq + Orchestrator
**Purpose:** speech → Groq reasoning → policy-gated tools → spoken result · **Depends on:** M01, M02 · **Files likely touched:** `api/ofa/engine/{base,groq,fake,registry,system.md}.py`, `api/ofa/{orchestrator,verify,memory,tools}.py`, `api/tests/ofa/test_{engine,orch,e2e_fake}.py`, `docs/ofa/bench/engine-prompts.yaml` · **Done when:** R1–R5, R7, R8, S6, S8, B9 pass; model choice recorded.

Read: §3, §7.1, §7.3, §8.2; plan 06, 02 §Data flow + §Tool surface, 04 §Principles.

## Steps
1. `engine/base.py` exactly per 06 interface; `fake.py` replays scripted `EngineEvent` lists from YAML.
2. `engine/groq.py`: httpx AsyncClient, SSE parsing of `chat.completions` stream incl. `tool_calls` deltas; usage from final chunk; TTFT/latency; rate-limit headers → metrics; errors → `EngineError` codes `RATE_LIMIT|ENGINE_DOWN|BAD_REQUEST|NO_VISION`. All request bodies pass `egress.guard` before send.
3. `registry.py`: `get_engine(config)`; `OFA_ENGINE=groq|fake`, `OFA_GROQ_MODEL` (default from step 7).
4. `tools.py`: JSON schemas for the 02 tool surface; each maps to an `ofa_execution` `Step` (never direct OS calls). Results wrapped `{"untrusted": true, "data": ...}`; truncate to 4 KB per result.
5. `memory.py` (SQLite `%LOCALAPPDATA%/OFA/memory.db`): profile (D0), context (current app, last results, last file, pending), learned mappings with view/edit/delete CLI (`python -m ofa memory ...`).
6. `orchestrator.py`: turn loop (06), max 25 tool calls, loop detector, verify before completion phrase, `ask_user` tool → TTS + next transcript returned as data. Rate limit/outage → speak + ask (Tier 1 question bound) — never switch silently. Plug in as M01 `TurnHandler`. TTS text passes `egress.guard` (V7).
7. **Model comparison** (live, cap 60): `scripts/bench_engine.py` runs `docs/ofa/bench/engine-prompts.yaml` (15 prompts: 5 single tool, 5 multi-step, 3 injection, 2 Hinglish) on gpt-oss-120b, gpt-oss-20b, qwen3.8-27b; scores tool/args correctness, injection resistance, TTFT, cost; writes `docs/ofa/bench/engine-2026-MM-DD.md`; records actual `x-ratelimit-*` values. Set default model; PLAN-DELTA if not gpt-oss-120b.
8. Fast-path measurement: same 5 simple commands via HassIL grammar vs engine; table into the same bench file; ask user (N9); default off.
9. End-to-end fake test: fake STT "open notepad" → fake engine tool_call open → Gate tier 1 (named in transcript) → fake hand → verify → TTS "Completed. Anything else?".
10. Live e2e (user-run): "Open Notepad and type hello" via voice.
