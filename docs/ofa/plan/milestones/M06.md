# M06 — Dictation (C4)
**Purpose:** verbatim + compose writing into any field · **Depends on:** M04, M05 · **Files likely touched:** `api/ofa/dictation.py`, `api/ofa/text/punctuation.py`, `api/ofa/tools.py`, `api/tests/ofa/test_dictation.py` · **Done when:** D1–D7, B8 (dictation pause) pass.

Read: §5 C4, §4.2 (pauses, script); plan caps/C4, 03 §Routing (dictation row), 04.

## Steps
1. `dictate` tool + mode selection; dictation session uses router `mode="dictation"` (long-pause turn policy).
2. Punctuation command map EN/HI (`comma`, `full stop`, `question mark`, `new line`, `poorna viraam`, `prashn chinh`); applied only when spoken alone between pauses (avoid eating "comma" inside content — rule: surrounded by ≥ 300 ms pauses or explicit prefix "punctuation").
3. Script normalization via `translit` per user pref; no other change (test: token sequence identical apart from script).
4. Critical-token check: words with conf < 0.85 that are names/numbers/dates/negations → speak "I heard <X>. Correct?" (lexicon YES/NO; NO → user respells/repeats).
5. Type → read back (UIA ValuePattern / TextPattern; Electron fallback: select-all+copy, non-secret only, restore clipboard) → exact diff; mismatch → fix once, else report.
6. Compose: engine drafts; show on screen + speak; revisions by voice; then type. Sending = Tier 2 via 04 (D7).
