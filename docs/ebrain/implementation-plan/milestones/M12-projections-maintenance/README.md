## Ordered implementation

1. **CP12.1 — deterministic card materializer.** Generate fields, state, timeline, sources/aliases/links and ledger/identity/policy watermarks only from approved ledger inputs. Each factual field has exact sanitized evidence/span or explicit system-derived reason; generated prose separate. Cards are caches and cannot grant identity/authority. Resolve equivalent codes and conflicts consistently with M11.
2. **CP12.2 — shadow rebuild and independent checks.** Rebuild into new generation at identical cut, catch up deltas, compare identity/bindings/card-state digests/current/conflict/fences/source coverage/scope. Run independent reference replay plus labelled identity samples, since two identical bad mappings can agree. Mismatch that threatens current correctness automatically fences/disables affected projection and uses safe authoritative replay, not authoritative data deletion. Swap pointer only after reconciliation/required approval.
3. **CP12.3 — incremental idempotent consolidation/lint.** Typed contradiction first: same fact, overlapping effective interval, incompatible normalized values. Advisory NLI only after scope/subject/time gate, never certainty or automatic resolution. Dedup issue target+rule+evidence revision. Check missing/corrupt citations, orphan steward, stale source, broken link, unbound claim, invalid grant, fence age, watermark, pending debt and erased dependencies. Schedule bounded fair jobs, dead letter failures, no repeated suggestion spam.
4. **CP12.4 — derived artifacts and citations.** Opt-in/approved policy only; source dependency DAG, model/prompt manifest and creation cut, dedup content/source-set and depth/cycle guard. Derived/recommendation/external never independent corroboration or current. Human adoption is separately authorized sourced decision. Retraction/erasure propagates unsupported/pending to dependents. Exact span/digest/typed subject/value/unit/negation checks where possible; unsupported prose omitted or labelled inference. String occurrence or model self-judgment is not proof.
5. **CP12.5 — answer and receipt integration.** Deterministic structured payload always usable without synthesis. Optional grounded prose may not add unsupported claim or hide conflict/intended-observed distinction; fallback to structured answer if verification fails. Compact voice keeps critical statuses/scope/evidence under declared budget. Receipt captures generated/sent, scoped bundle hash/snapshot/versions/clipping; actual ack/use telemetry in M13. Client feedback only bounded offline ranking experiments, no state mutation.
6. **CP12.6 — measured ablations and maintenance cost.** Disable classifier/vector/graph/rerank/widening/consolidation suggestions one at a time in isolated tests, retain required safety. Report joint/legacy/zombie, filing/recall/abstention, latency, job cost and human-minutes per 1k facts. Negative control corrupts cache and repeats hallucinated summaries; tests must detect them. Keep only measured gains or necessary invariants; no component justified solely by draft architecture.
