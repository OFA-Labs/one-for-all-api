## Ordered implementation

1. **CP8.1 — schema and restricted roles.** Add org/scope/principal/membership/grant/policy/predicate/source/event/claim/identity/proposal/outbox/pending/watermark/usage/audit/erasure metadata structures from V3 §7.1. Build only needed columns with composite org/scope FKs, unique scoped op/idempotency keys, enum/check constraints and migration checksums. Runtime is non-owner, non-superuser, NO BYPASSRLS. FORCE RLS, USING/WITH CHECK for every tenant table; separate migration/backup credentials from API/worker. Test setup is an isolated named DB, never owner default data.
2. **CP8.2 — trusted context.** Server derives principal, org, permitted project/predicate/actions, authority and source contract. Use transaction-local DB context on each pooled checkout; verify cleanup and cannot set arbitrary tenant from client body. Fail closed on absent/expired/empty grants. Initial synthetic principal adapter is explicitly development-only; no assertion that it is SSO. Separate auth-admission check at commit from current read checks.
3. **CP8.3 — pre-persistence gate.** Parse strict bounded input, allowlisted formats, encoding/recursion/decompression limits, scanner status and redact/reject secrets/PII before durable event, logs, queues or model context. Rejected payload retains minimal metadata only. Unknown scanner state fails closed or restricted ephemeral TTL quarantine; no hidden raw copy. Establish sanitized source revision/span mapping, source digest and encrypted optional object staging/orphan cleanup.
4. **CP8.4 — atomic admission.** Lock organization state row, revalidate grants/policy, check scoped idempotency digest, reserve usage, allocate transactional commit counter, append normalized immutable event/claim, exact admitted transition or pending impact, outbox and receipt, then commit/ack. Do not use standalone sequence as proof of commit order. No model/network calls under commit lock. Retry same key+digest gives same authorized receipt; different digest conflicts. Atomic baseline budgets include events/bytes/pending/jobs, even before M14 commercial plans.
5. **CP8.5 — outbox and fences.** At-least-once stable job keys, lease/fencing, transactional applied markers, bounded retry/backoff/dead letter, contiguous watermark and separate pending state. A crash between event commit and projection cannot lose work. Eligible ambiguous incoming claim fences known possible facts/domain before ack; incapable/external writes cannot fence a human fact just by mentioning it. Unknown domain rejected/evidence-only. Worker failure leaves fence until a committed reviewed outcome.
6. **CP8.6 — snapshots and pure exact slice.** Add snapshot/authorized input-loader/min_seq contract, server valid/recorded clocks, identity/policy version and primary read cut. Supply a minimal pure exact resolver for fixtures, explicitly extended in M11. Query sees committed exact/delta transitions or pending; never old card current after an acknowledged relevant write. Final auth epoch recheck before delivery. Unsatisfied min_seq/replica lag returns pending/unavailable or primary fallback.
7. **CP8.7 — erasure/recovery seams and safety flags.** Record restricted suppression/tombstone references, content retention classes and restore epoch dependencies before introducing backups/models. Suppressed content must be unreadable at all history cuts. New shared routes remain disabled; validate config cannot bypass auth, gate, approval, evidence or cardinality. Do not import/delete real SQLite data.
