## Ordered implementation

1. **CP9.1 — typed canonical keys.** Predicate registry defines required qualifiers, cardinality/value type/normalization, accepted sources, writer policy and freshness. Keys include org/scope/stable resource/predicate/kind/qualifiers. Exact units normalize deterministically; token type/environment/branch/repo never stemmed away. Unknown qualifiers are not defaults. Initially reject unsupported set predicates explicitly. Atomic unique register prevents duplicate fact creation on concurrent identical keys; IDs never reused.
2. **CP9.2 — identity event replay.** Implement REGISTER/BIND/UNBIND_CORRECTION/ALIAS/RETIRE_ALIAS/MERGE/SPLIT/REKEY with actor/evidence/approval/generation and temporal cut. Exactly one active binding per applied claim at each identity cut; unassigned claims pending, not independent current cards. Legacy codes/op IDs are scoped aliases, not authority or globally unique assumptions. Resolve explicit fact/lineage only after scope/qualifier/base compatibility; conflicting path and target/multiple target facts reject or review. No arbitrary “first target.”
3. **CP9.3 — source contracts and snapshots.** Stable source IDs/upstream revisions/digests, parser version, ACL lineage, sanitized offsets/spans. Dedup scoped identical revision. Rename retains resource identity; partial scan/permission failure does not mean source deleted. Confirmed retraction emits status event; effect on approved decision follows predicate/source contract. No raw permanent meeting/chat archive. Reviewed opt-in durable engineering conclusions become separate approved source artifacts.
4. **CP9.4 — deterministic filing first.** Authorized structured ID/full key then approved exact alias lookup within qualifiers. Similarity never overrides these. Alias ambiguity yields missing qualifiers/pending. Exact evidence-derived binding records reason/generation transactionally and clears appropriate fences only at committed resolution. A lower-authority or external input cannot invent an authoritative fact/head.
5. **CP9.5 — bounded model suggestions.** Under D02/D07, async isolated local classifier gets only sanitized authorized candidates and returns strict IDs/new-key/confidence/near-miss/spans/missing-qualifier/reason/manifest schema. Validate IDs and anchors server-side; no tools, network or write credentials. Model-only equivalence is a proposal, not an applied binding between existing facts. Pin artifact/tokenizer/runtime/preprocess/schema/calibration hashes. Unavailable classifier leaves pending and eligible fences; no unapproved provider fallback.
6. **CP9.6 — merge/split review and calibration.** Immutable proposal contains exact mappings, keys/qualifiers, source proof, timeline/current preview, affected scopes/quota, prior generation and digest. Separation-of-duties + CAS; split maps each claim once or pending, never authoritative duplication. No transitive similarity equality or cross-project value merge. Build disjoint fact-family/repo/template/locale/domain calibration/test sets with hard negatives, missing qualifiers, units, Unicode and OOD. Threshold prioritizes review, not permission; measure false merge/split, total eligible filing accuracy including pending misses, coverage and human effort. Drift/low-sample strata revert to exact-only filing.
