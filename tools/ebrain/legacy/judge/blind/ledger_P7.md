## 1. What each source actually is

**KB-01 Engram.** At the pinned SHA engram is a Go CLI plus six agent skills and a Claude Code mod over a flat Obsidian-compatible Markdown "zettelkasten" vault: atomic notes (feedback / fact / runbook / QA) with frontmatter, `.vec.json` MiniLM sidecars, typed `supersedes` edges, and an append-only JSONL chunk index of raw transcripts. Retrieval is local cosine + recency + k-means clustering; an automatic-memory mod runs a cheap Haiku gate then Sonnet judges at each prompt and turn end to deliver notes and write lessons. Multi-vault "parent" sync uses pending offers, hash-checked curation and an outbox. Its distinctive asset is a rigorous evaluation ledger, several rows of which refute its own earlier ideas.
- Claimed: "self-correcting memory; learns from sessions, identifies memories that are not being followed, evaluates them, fixes memory problems." Found: **true of the March 2026 version only.** Then: per-memory followed/contradicted/ignored/irrelevant counters, a Haiku FOLLOWED/NOT_FOLLOWED/IRRELEVANT evaluator on Stop, Working/Hidden-Gem/Leech/Noise quadrants, and a decision tree proposing rewrite/narrow/escalate/delete. All of it was deleted 2026-03-30…04-02. At the pin, "learns from sessions" is true (turn judge, transcript sweep); "not followed" detection is replaced by use-driven activation (`LastUsed`) and supersession; fixes are agent-judged amend/supersede, not measured follow-rates. **KB-02 Remcycle.** A Python (stdlib-only) command `dream` plus a Claude Code mod. Session end copies verbatim prose into a SQLite/FTS5 archive (secrets redacted); once a day a background "dream" asks Sonnet to extract quote-backed claims per unread session, then plain code checks quotes, sets provenance, reconciles by authority/recency into a git-tracked mirror of Claude Code's memory folder, stages the change, gates it, and swaps it in atomically. - Claimed: "reviews previous sessions, identifies stale or contradictory memories, preserves decisions, improves future session context." Found: **confirmed.** Review trigger: daily, started by the first session after 20 h (daily.py L15-62); staleness: missing repo anchors (dreaming.py L398-421), `dream review` dated flag, 14-day thread expiry; contradiction: reconcile Question/Contest ops and review `contradicts` pairs, all quote-verified; decision preservation: decisions/preferences never superseded by weaker claims and pre-existing memories never replaced without a ruling. Deleted vs archived: nothing is hard-deleted by the dream — withheld files move to `.remcycle/withheld/`, retired entries stay on file, superseded statements go to `history`, dropped index lines stay searchable; only `dream purge --yes` deletes archive sessions. Evidence: https://github.com/lianmatsuo/remcycle/blob/be1e27cd293e607b1e0c4807fd7dfd7aef28d02e/src/dream/reconcile.py#L136-L153 , https://github.com/lianmatsuo/remcycle/blob/be1e27cd293e607b1e0c4807fd7dfd7aef28d02e/src/dream/memory.py#L172-L179

## 2. Per-source verdict

- **KB-01 Engram — ADAPTED.** Take: typed supersession with ride-along (P7-01-04), use-driven activation and recency decay (01-09/10), judged-version hash check (01-13), pending-offer quarantine (01-14), delivery framing (01-06), two-tier turn gating (01-01) and the evidence ledger (01-22). Do not take: per-prompt multi-call Sonnet delivery (too slow/costly for voice; LEDGER shows memory raised op cost), Luhmann placement, parent-vault tree. The deleted follow-rate loop (01-23..25) is the only explicit "memory not followed" detector found anywhere; its abandonment is evidence that it was hard to make reliable, not proof it cannot work.
- **KB-02 Remcycle — ADOPTED (core).** Python, laptop-only, explainable, transactional and evidence-backed: quote verification, provenance downgrade, deterministic reconcile, stage-gate-swap mirror with git history, probe-question retrieval gate, human ruling queue. It is single-user, single-agent (Claude Code) and once-a-day; concurrency across several agents and real-time capture must be added.
- **KB-03 gbrain — ADAPTED.** The conceptual reference for event-sourced memory (compiled truth + timeline, belief ledger, page-at-time, revision CAS + idempotent receipts, trust tiers, write gate, fail-closed scoping, budgeted context_pack/delta). Its scale (16k files, Postgres, 40+ cycle phases, TLA+) is far outside a 4-week one-developer MVP; re-implement a small subset in Python/SQLite.
- **KB-04 Claude Mnemonic — ADAPTED (narrowly).** Useful: layered pre-filters before LLM calls, `<private>` stripping and self-reference filters, explainable score breakdown, vector→FTS→recent fallback, the dashboard shape. Rejected: permissive "be generous" extraction without provenance, auto-global scope from tags, hard deletion on LLM "INVALID", and the unwired conflict/graph/LEANN features.

## 4. Gaps no source covers (relative to E-Brain needs)

- **Concurrent contradictory writes from several *different* agents.** gbrain has revision CAS + idempotent receipts and trust tiers, engram a vault flock and hash check, remcycle a single writer. None reconciles two agents asserting conflicting facts at nearly the same time with different authority (e.g. Codex vs the voice agent), nor attributes authority per agent identity beyond "agent_written".
- **Version correctness / time travel for small installs.** Only gbrain has bitemporal recorded/valid time (Postgres-scale). Remcycle has git history of the mirror and per-slot `history`; engram and mnemonic have none. No lightweight SQLite design exists.
- **Agent and user isolation.** gbrain source scoping is the only fail-closed model; remcycle scopes by project; mnemonic's unwired hybrid path ignores its filter. None isolates *between agents of the same user* (e.g. Codex may not read voice-agent private context).
- **Prompt injection and memory poisoning from the web.** gbrain's write gate and labels, engram/remcycle framing and quote checks exist; none handles content captured from browsed web pages by a voice browser agent (OFA's main input), nor spoken instructions mis-transcribed by STT.
- **Human-readable visual brain.** No source ships an interactive knowledge-graph/timeline/conflict view combining provenance, freshness and pending rulings. Closest: remcycle `/remcycle` pane, mnemonic Vue dashboard, gbrain Markdown + admin SPA, engram via Obsidian.
- **Token budgeting for voice latency.** Budgets exist (remcycle 4 000-char pack, gbrain `budget_tokens`, mnemonic 16k, engram 60 000 chars) but none targets a sub-second voice turn or measures latency of injection on spoken responses.
- **Cost on free tiers.** Remcycle and mnemonic assume a Claude subscription via the CLI; gbrain defaults to paid Voyage embeddings/reranker; engram uses Sonnet per prompt. No source plans for free-tier rate limits, provider fallback, or a hard daily token cap across agents (gbrain has per-phase $ caps only).
- **Measured "memory not followed" detection at low cost.** Only engram's deleted evaluator; remcycle's correction-after-follow is the cheap partial substitute.
