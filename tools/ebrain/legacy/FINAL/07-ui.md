### 3.3 `http-client.ts`

`createHttpEBrainClient(baseUrl: string, token: string): EBrainClient`. Every method calls `fetch(baseUrl + path, { headers: { Authorization: "Bearer " + token, "Content-Type": "application/json" } })`. A non-2xx response throws `EBrainHttpError(res.status, text)`.

### 3.4 `client.ts`

```ts
import type { EBrainClient } from "./contracts";
import { createMockEBrainClient } from "./mock-client";
import { createHttpEBrainClient } from "./http-client";
export function getEBrainClient(): EBrainClient {
  const url = process.env.NEXT_PUBLIC_EBRAIN_API_URL;
  return url ? createHttpEBrainClient(url, process.env.NEXT_PUBLIC_EBRAIN_TOKEN ?? "") : createMockEBrainClient();
}
```

### 3.5 `use-ebrain-limits.ts` (in the feature folder, because it is feature-specific)

```ts
"use client";
import { useEffect, useState } from "react";
import type { EBrainClient, Limits } from "@/lib/ebrain/contracts";
export type LimitsState =
  | { state: "loading" } | { state: "error"; baseUrl: string; error: unknown } | { state: "ready"; data: Limits };
export function useEBrainLimits(client: EBrainClient): LimitsState {
  const [s, setS] = useState<LimitsState>({ state: "loading" });
  useEffect(() => {
    let live = true;
    client.getLimits().then((data) => live && setS({ state: "ready", data }),
                            (error) => live && setS({ state: "error", baseUrl: client.baseUrl, error }));
    return () => { live = false; };
  }, [client.baseUrl]);  // fetched once per mount; no polling
  return s;
}
```

## 4. Components and exact copy

Every number and sentence comes from `Limits`. **No component hard-codes a number** (R-071).

**(a) CapacityMeter (M1, R-070).**
- Markup: `<section className="panel ebrain-meter" aria-label="Memory capacity">`, containing `<meter min={0} max={capacity_hard} low={capacity_soft} high={capacity_hard} optimum={0} value={Math.min(memory_count, capacity_hard)} aria-label="Memories used"/>`, a text line, and a `Pill` with the state word.
- `fill(t) = t.replace("{n}", n.toLocaleString("en-US")).replace("{hard}", hard.toLocaleString("en-US"))`.

| State | Text | Pill (tone, text) | Extra |
|---|---|---|---|
| ok | `fill(copy.meter_ok)` → "412 / 1,000 memories — inside the tested range" | `success`, "Inside tested range" | none |
| near_limit | → "912 / 1,000 memories — close to the tested limit" | `warning`, "Near limit" | none |
| beyond_tested_range | → "1,240 / 1,000 memories — beyond the tested range: answers are unreliable" | `danger`, "Beyond tested range" | `<Notice tone="danger">{copy.capacity_note}</Notice>` |

- Always below the line: `<p>{copy.capacity_note}</p>`, which renders "This stores your first ~1,000 memories reliably-ish. Beyond that it is unreliable — this is a known limitation of the project as of now."
- Also `<details><summary>What counts as a memory?</summary>One saved note, decision or file version from any agent. Edits are new memories; nothing is overwritten.</details>`.
- `e-brain.css` sets only `.ebrain-meter meter { width: 100%; height: 12px; }` and `.ebrain-meter p { color: var(--t-text-muted); }`. The colour comes from the existing `Pill` and `Notice` tones.

**(b) HonestyPanel (M3, R-071).**
- Heading `h2` "What this can and can't do", with two lists: "Can" (`can: true`) and "Can't reliably".
- Each row shows: `example`; a `Pill` with `tier`; and "measured: {metric} {at_1k} at ~1k memories, {at_10k} at ~10k".
- The footnote is `measured_source`.

**(c) MemoryList (M3, R-072).** It shows `listChains()` 50 at a time (a "Load more" button uses `next_cursor`). Each row has the head text, its badges, and a "Why am I seeing this?" button that opens `Dialog` from `existing:one-for-all-web/src/components/ui/dialog.tsx`.

| Badge | Source | Glyph + text |
|---|---|---|
| current | `status` | `●` current |
| superseded | version `status` | `○` superseded |
| conflicted | `status` / flag `conflict` | `⚠` conflicted |
| possible_same_fact | flag | `≈` possibly the same fact |
| untrusted | flag | `⛔` untrusted (external) |
| beyond_tested_range | `capacity_state` | `⤒` beyond tested range |

- A legend lists all six.
- The drawer shows `getChain()` versions: code, ts, agent, authority, provenance, status, supersedes, and a "silent update" tag when `silent`.
- It also shows the redacted text and the `op_id`s, plus the replay reason: "newest admissible write (T1)" for current; "human value outranks agent (T2)"; "external content never overrides first-party (T3)" for untrusted; "same-time writes from two agents (T4)" for conflicted.

**(d) Known flaws (M3, R-073).** Heading `h2` "Known flaws (measured)". It is always rendered, one row per `known_flaws[]`: "{text} — {metric}: {at_1k} at ~1k, {at_10k} at ~10k".

**(e) PairsReview (M4, R-074).**
- When `subject_join === "off"`: the text "Same-fact detection is OFF (experimental; it did not help in tests)."
- Otherwise, per pair: both chains' heads, and the buttons "Same fact — merge" (`confirmPair`), "Different facts" (`splitPair`) and "Decide later".
- The toast says "Saved. You can undo this with Rollback."

**(f) HealState (M3; Approve in M4, R-075).**
- `<Pill>{copy.heal_state[heal_mode]}</Pill>`, for example "Self-heal: approval required".
- The line: "Automatic healing hid correct memories in tests ({heal_harm.at_1k} at ~1k, {heal_harm.at_10k} at ~10k), so every change waits for you."
- Then a list of `getHeal().proposals`. M4 adds "Approve" (`approveHeal`) and "Dismiss", which writes nothing.

**(g) States and accessibility (M3, R-076).**
- Loading: `aria-busy="true"` and "Loading memory…".
- Empty: `EmptyState` titled "No memories yet", described as "Claude Code, Codex and the voice agent will add them as you work."
- Error: `Notice tone="danger"` with "E-Brain service is not reachable at {baseUrl}. Nothing was changed." and a Retry button.
- There is exactly one `h1` (PageTitle). Everything is reachable by keyboard; Esc closes the drawer. There is no horizontal scroll at 375 px, and axe finds no WCAG 2 A/AA violations.
